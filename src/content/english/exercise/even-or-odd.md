Write a function called <define>`evenOrOdd`</define> that takes a number as its input and returns a string specifying whether the number is `"Even"` (0, 2, 4, 6, 8, etc), or `"Odd"` (1, 3, 5, 7, etc).

To approach this problem, think about what it is that actually makes a number odd or even. Remember that you can use the remainder operator (`%`).
