Σε αυτή την άσκηση, η αποστολή σου είναι να σχεδιάσεις ένα εικονίδιο καιρού για μια βροχερή μέρα με τον ήλιο να κρυφοκοιτάζει πίσω από τα σύννεφα. Όταν τελειώσεις, θα πρέπει να δείχνει κάπως έτσι:

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="Ολοκληρωμένη σκηνή με σύννεφο, βροχή και ήλιο" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Σχεδιάσαμε ένα πρότυπο για σένα. Τα σχήματά σου πρέπει να βρίσκονται ακριβώς μέσα στις γραμμές. Προσθέσαμε επίσης τη βάση του σύννεφου στον κώδικα για να σου διευκολύνουμε λίγο τα πράγματα. **Δεν μπορείς να αλλάξεις αυτήν τη γραμμή** (θα δεις ότι είναι γκριζαρισμένη και υπάρχει ένα σύμβολο κλειδώματος δίπλα της).

Θα χρειαστείς τις συναρτήσεις `circle` (κύκλος) και `ellipse` (έλλειψη). Θα πρέπει να χρησιμοποιήσεις ελλείψεις μόνο για τις σταγόνες βροχής. Αν τις χρησιμοποιήσεις για τον ήλιο ή τα σύννεφα, δεν θα λειτουργήσει.

### Πώς θα βρεις τις σωστές συντεταγμένες

Σε αυτή την άσκηση **μπορείς** να περάσεις τον δείκτη πάνω από τον χώρο σχεδίασης για να βρεις συντεταγμένες. Και πάλι, όλοι οι αριθμοί που χρησιμοποιούνται **διαιρούνται με το 5, με μία εξαίρεση**. Η οριζόντια ακτίνα των σταγόνων βροχής είναι `3`. Κάθε άλλος αριθμός, συμπεριλαμβανομένης της κατακόρυφης ακτίνας των σταγόνων βροχής, διαιρείται με το 5.

Καλή διασκέδαση!
