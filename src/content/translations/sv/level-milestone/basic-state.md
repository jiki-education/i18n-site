Bra jobbat på den här. Du kan nu följa värden som ändras medan ditt program körs, vilket är ett stort steg framåt jämfört med var du var för några nivåer sedan.

Idén om tillstånd kommer att återkomma genom hela kursen, och den blir mer intressant varje gång vi kombinerar den med något nytt.

Nästa nivå är rejäl. Vi kommer att titta på funktioner som returnerar värden, och sedan utforska färger, slumpmässighet, animation, scope och nästlade loopar på vägen. Ha det så roligt!
