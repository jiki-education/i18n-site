# i18n.jiki.io

Public review site for the [Jiki & Exercism Translatathon](https://jiki.io/blog/translatathon).

Every translation we generate is published here next to the English it came from, along
with the agreed glossary behind each language, so native speakers can read both and tell us
what's wrong on [the forum](https://forum.jiki.io/c/i18n/67).

## Running it

```bash
./bin/dev     # http://local.jiki.io:3068
```

## Where the content comes from

Nothing under `src/content/` is written by hand. It is generated by the publish scripts in
the sibling [`translator`](https://github.com/jiki-education/translator) repo, which is the
control panel for all translation work:

```bash
cd ../translator
./scripts/publish-glossary    all
./scripts/publish-translation hu concept using-functions
```

Commit and push here to deploy, then announce on the forum.

## Deployment

Push to `main`. GitHub Actions builds the static site and deploys it to Cloudflare Workers
at `i18n.jiki.io`.

## Lifespan

This site is disposable. It exists for the Translatathon weekend and will be deleted
afterwards. The translations themselves live in the Jiki source repos, and the glossaries
live in `translator`. Nothing here is a source of truth.
