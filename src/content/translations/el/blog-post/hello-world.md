## Καλώς ήρθες στο Jiki!

Καλώς ήρθες στο **Jiki**! Είμαστε πραγματικά ενθουσιασμένοι που είσαι εδώ.

## Τι είναι το Jiki;

Το Jiki είναι μια διαδραστική πλατφόρμα που έχει σχεδιαστεί για να σε βοηθήσει να μάθεις να γράφεις code. Είναι χτισμένο γύρω από μια απλή ιδέα: **μαθαίνεις να γράφεις code γράφοντας code**, όχι βλέποντας βίντεο, κάνοντας κουίζ ή λύνοντας απλές ασκήσεις.

Από την πρώτη μέρα, θα χτίζεις πραγματικά projects - παιχνίδια, animations και εργαλεία - γράφοντας **δεκάδες, μετά εκατοντάδες (ίσως και χιλιάδες)** γραμμές code. Υπάρχει ένας χαρακτήρας που λέγεται **Jiki** και τρέχει το code σου, δείχνοντάς σου ακριβώς τι συμβαίνει καθώς εκτελούνται τα προγράμματά σου. Αυτό κάνει το αόρατο ορατό, βοηθώντας σε να καταλάβεις πώς λειτουργεί πραγματικά ο code.

Διδάσκουμε είτε μέσω **JavaScript** είτε μέσω **Python** (ίδιο πρόγραμμα σπουδών - εσύ επιλέγεις τη γλώσσα), αλλά έχουμε προσαρμόσει την εμπειρία ώστε να αφαιρέσουμε τα σημεία που μπερδεύουν και δυσκολεύουν τους αρχάριους. Καθώς προχωράς, ξεκλειδώνονται περισσότερες δυνατότητες.

Σε μια εποχή τεχνητής νοημοσύνης όπου ο Claude και το ChatGPT μπορούν να γράφουν code για σένα, το Jiki εστιάζει σε δύο πράγματα που εξακολουθούν να έχουν πραγματική σημασία: την κατανόηση των **θεμελιωδών εννοιών** του πώς λειτουργεί ο code (ώστε να μπορείς πραγματικά να διαβάζεις και να σκέφτεσαι τι κάνει η AI σου), και το να μάθεις πώς να **χτίζεις** - πώς λειτουργούν οι ιστοσελίδες κάτω από το καπό, πώς να σχεδιάζεις βάσεις δεδομένων, πώς να αρχιτεκτονείς λογισμικό.

## Για ποιους είναι το Jiki;

Το Jiki έχει σχεδιαστεί για **απόλυτους αρχάριους** - ανθρώπους που δεν έχουν γράψει ποτέ ούτε μία γραμμή code, ή που δοκίμασαν να μάθουν αλλά κόλλησαν.

Μπορεί να είσαι:

- **Εντελώς νέος στον προγραμματισμό** και θέλεις έναν δομημένο τρόπο για να ξεκινήσεις
- **Κολλημένος στο «tutorial hell»** - έχεις δει αμέτρητα βίντεο αλλά δεν μπορείς να χτίσεις τίποτα
- **Κάποιος που δοκίμασε άλλα μαθήματα** αλλά τα βρήκε πολύ γρήγορα, πολύ αργά ή πολύ θεωρητικά
- **Ένας ενδιάμεσος προγραμματιστής** που θέλει να εδραιώσει τις βασικές του γνώσεις (περίπου το 50% των μαθητών μας!)

Αν έχεις νιώσει ποτέ ότι τα μαθήματα προγραμματισμού σου μαθαίνουν σύνταξη αλλά δεν σου μαθαίνουν να _σκέφτεσαι_ πραγματικά σαν προγραμματιστής, το Jiki είναι για σένα.

## Γιατί δημιουργήσαμε το Jiki;

Πιστεύουμε ότι το να μάθεις να γράφεις code είναι πολύτιμο σχεδόν για όλους. Οι περισσότεροι πόροι εκμάθησης προγραμματισμού δεν πιάνουν την ουσία του τι είναι πραγματικά ο προγραμματισμός: **διασκεδαστική επίλυση προβλημάτων**. Σου δίνουν βίντεο να δεις και κουίζ να κάνεις, αλλά δεν σε βάζουν να _φτιάξεις_ πράγματα. Έτσι φτιάξαμε το Jiki για να το αλλάξουμε αυτό.

Θέλεις την πλήρη ιστορία; Διάβασε το blog post μας: **[Το παρασκήνιο του Jiki](/blog/the-backstory-of-jiki)**.

Το Jiki δεν θα υπήρχε χωρίς την υποστήριξη τόσων ανθρώπων.

- **Aron και Nicole**: Σας ευχαριστώ για όλη τη σκληρή δουλειά που κάνατε για να το φτιάξουμε μαζί. Ήταν ένα αληθινό ταξίδι και δεν θα τα είχα καταφέρει χωρίς εσάς.
- **Οι μαθητές του bootcamp μας**: Σας ευχαριστούμε που γίνατε τα πειραματόζωά μας! Η ανατροφοδότηση, η υπομονή και ο ενθουσιασμός σας βοήθησαν να διαμορφώσουν το Jiki όπως είναι σήμερα.

- **Mentors του bootcamp**: Μια τελευταία αναφορά στους ανθρώπους που βοήθησαν να διαμορφωθεί το bootcamp μέσω του mentoring. Δεν έχετε ιδέα πόση υποστήριξη ένιωσα από εσάς κατά τη διάρκεια αυτών των 6 μηνών και πόσο με βοηθήσατε στη σκέψη μου γι' αυτό.

## Δοκίμασέ το

Θα ήθελα πολύ να **[δοκιμάσεις το Jiki](https://jiki.io/auth/signup)** και να δεις τι πιστεύεις.

Αν είσαι σχετικά νέος στον προγραμματισμό (ή απόλυτος αρχάριος), τότε ελπίζω να απολαύσεις πραγματικά τη μάθηση μέσα από αυτό. Θα ήθελα πολύ να μάθω πού κολλάς ή απογοητεύεσαι - αυτή η ανατροφοδότηση είναι ανεκτίμητη για να το κάνουμε καλύτερο.

Αν είσαι ήδη προγραμματιστής, πρέπει να είμαι ειλικρινής: αυτό δεν έχει σχεδιαστεί για σένα. Πιθανότατα θα σου φανεί αρκετά βασικό και αργό. Αλλά πίστεψέ με, για τους αρχάριους φαίνεται γρήγορο και έντονο! Θα ήθελα παρόλα αυτά να παίξεις και να μου δώσεις τα σχόλιά σου. Τα έμπειρα μάτια σου αναμφίβολα θα εντοπίσουν πράγματα που οι αρχάριοι δεν θα σκέφτονταν να αναφέρουν. Και αν ξέρεις κάποιον που σκέφτεται να μάθει προγραμματισμό, θα εκτιμούσα πραγματικά να του μιλήσεις για το Jiki. Αυτή η υποστήριξη από στόμα σε στόμα σημαίνει τα πάντα!
