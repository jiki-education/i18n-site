Στην πρώτη άσκηση με τον λαβύρινθο μετακινούσες τον χαρακτήρα σου χειροκίνητα. Τώρα είσαι έτοιμος να λύσεις οποιονδήποτε λαβύρινθο με κώδικα, προγραμματιστικά!

Για να γίνει αυτό δυνατό, έχεις τρεις νέες συναρτήσεις:

- `canTurnLeft()` (μπορεί να στρίψει αριστερά): επιστρέφει `true` αν ο χώρος στα αριστερά του χαρακτήρα δεν είναι τοίχος.
- `canTurnRight()` (μπορεί να στρίψει δεξιά): επιστρέφει `true` αν ο χώρος στα δεξιά του χαρακτήρα δεν είναι τοίχος.
- `canMove()` (μπορεί να προχωρήσει): επιστρέφει `true` αν ο χώρος μπροστά από τον χαρακτήρα δεν είναι τοίχος.

Όταν τα συνδυάσουμε αυτά με τις `move()` (κίνηση), `turnLeft()` (στρίψιμο αριστερά) και `turnRight()` (στρίψιμο δεξιά) που είχες πριν, είναι δυνατό να γράψουμε έναν αλγόριθμο που λύνει **οποιονδήποτε** λαβύρινθο. Ο "αλγόριθμος" είναι μια φανταχτερή λέξη που σημαίνει απλά "ένας τρόπος να κάνεις κάτι". Είναι σαν μια φόρμουλα ή μια συνταγή.

Πιο κάτω στις οδηγίες, θα σου πω τον αλγόριθμο έτοιμο για να τον λύσεις. Αλλά θέλω πρώτα να προσπαθήσεις να τον βρεις μόνος σου, σαν έναν μικρό γρίφο λογικής. Αν ξέρεις αν μπορείς να στρίψεις αριστερά, δεξιά ή να προχωρήσεις, πώς μπορείς να λύσεις οποιονδήποτε λαβύρινθο σου δίνω;

Μόλις τον βρεις, ή αν τα παρατήσεις, συνέχισε να διαβάζεις για να δεις την απάντηση και τι πρέπει να γράψεις σε κώδικα.

### Ο Αλγόριθμος

Εντάξει – ήταν δύσκολο, οπότε φαντάζομαι ότι μπορεί να είχες κάποιες ιδέες αλλά όχι ολόκληρη τη λύση. Να τα βήματα που πρέπει να ακολουθήσεις:

- Αν μπορείς να στρίψεις αριστερά, στρίψε αριστερά και προχώρα μπροστά.
- Αλλιώς, αν μπορείς να προχωρήσεις μπροστά, προχώρα μπροστά.
- Αλλιώς, αν μπορείς να στρίψεις δεξιά, στρίψε δεξιά και προχώρα μπροστά.
- Αλλιώς, γύρνα πίσω.

Αν το κάνεις αυτό, μπορείς να λύσεις οποιονδήποτε λαβύρινθο!

Γράψε αυτές τις οδηγίες σε κώδικα. Καλή διασκέδαση!
