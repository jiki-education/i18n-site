Καλώς ήρθες στο δεύτερο μέρος της σειράς Παντόγραμμα. Θυμήσου, ένα παντόγραμμα είναι μια πρόταση που χρησιμοποιεί κάθε γράμμα του αλφαβήτου τουλάχιστον μία φορά.

Αυτή η άσκηση είναι μια πιο σύνθετη εκδοχή της προηγούμενης άσκησης Παντόγραμμα που έλυσες, επειδή χρησιμοποιεί και κεφαλαία γράμματα. Αυτό προσθέτει απρόσμενα μεγάλη πολυπλοκότητα.

Δημιούργησε μια συνάρτηση με το όνομα `isPangram` (είναι παντόγραμμα) που δέχεται μια πρόταση ως συμβολοσειρά και επιστρέφει μια Boolean τιμή που δηλώνει αν είναι ή όχι παντόγραμμα.

Σου δώσαμε τον προηγούμενο κώδικά σου ως σημείο εκκίνησης.

### Βοηθητικές Συναρτήσεις

Εκτός από την υπάρχουσα βοηθητική συνάρτησή σου (για την οποία σου προτείναμε να την ονομάσεις `includes`), σου συνιστούμε να δημιουργήσεις δύο νέες βοηθητικές συναρτήσεις για να σε βοηθήσουν να λύσεις αυτή την άσκηση. Τα ονόματα των συναρτήσεων είναι τυπικά ονόματα, τα οποία σου προτείνουμε να κρατήσεις:

1. `indexOf(haystack, needle)`: Μια συνάρτηση που υπολογίζει **πού** βρίσκεται η βελόνα στα άχυρα. Αντί να επιστρέφει `true`/`false` όπως η `includes`, επιστρέφει τη **θέση** της βελόνας. Για παράδειγμα, `indexOf("Jeremy", "r")` θα επέστρεφε `2` (θυμήσου ότι μετράμε από το 0).
2. `toLowerCase(someString)`: Μια συνάρτηση που δέχεται μια συμβολοσειρά και την επιστρέφει μετατρεμμένη σε πεζά γράμματα. Για παράδειγμα, `toLowerCase("JeReMy")` θα επέστρεφε `"jeremy"`.

Καλή διασκέδαση!
