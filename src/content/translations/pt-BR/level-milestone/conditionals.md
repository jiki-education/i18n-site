Muito bem no nível de condicionais. Com sorte, if e else já estão começando a parecer bem naturais.

As condicionais são uma das ideias mais importantes da programação. Quase todo programa interessante precisa tomar decisões com base no que é verdade naquele momento, e agora você tem as ferramentas básicas para isso.

A seguir, vamos ver formas mais poderosas de escrever condições, combinando umas com as outras usando and/or, além de algumas ideias relacionadas, como o módulo. Divirta-se!
