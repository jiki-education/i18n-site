Καλή δουλειά που κατέκτησες τις μεταβλητές.

Οι μεταβλητές είναι μία από εκείνες τις ιδέες που είναι αρκετά απλές στην επιφάνεια, αλλά θα αποτελούν τη βάση για σχεδόν όλα όσα γράφεις από εδώ και πέρα. Η δυνατότητα να αποθηκεύεις μια τιμή, να της δίνεις ένα όνομα και να τη χρησιμοποιείς αργότερα, είναι αυτό που μετατρέπει τον κώδικα από μια σταθερή λίστα εντολών σε κάτι πραγματικά ευέλικτο.

Στη συνέχεια θα δούμε πώς οι μεταβλητές αλλάζουν με την πάροδο του χρόνου, που είναι αυτό που οι προγραμματιστές ονομάζουν «κατάσταση». Καλή διασκέδαση!
