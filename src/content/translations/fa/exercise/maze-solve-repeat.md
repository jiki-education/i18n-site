یک راه‌حل کارآمد برای یک هزارتو در اختیارتان قرار گرفته است، اما این راه‌حل خیلی طولانی و تکراری است. وظیفه‌ی شما این است که کد را به شکلی تغییر دهید که تا جای ممکن خطوط کمتری داشته باشد.

راز این کار استفاده از `repeat` «حلقه‌ها» برای کوتاه‌تر کردن کد است. برای مثال، یک «حلقه‌ی Repeat» به این شکل نوشته می‌شود:

```javascript
repeat(3) {
  // هر چیزی که می‌خواهید تکرار شود.
}
```

هدف شما این است که کد را تا حد امکان کوتاه کنید - **۲۲ خط کد**. این یعنی باید به این فکر کنید که چه زمانی استفاده از یک حلقه‌ی Repeat خوب است و چه زمانی نه. توجه کنید که خطوط خالی و خطوطی که فقط کامنت دارند در محاسبه‌ی هدف نهایی به حساب نمی‌آیند، بنابراین با خیال راحت کدتان را فاصله‌بندی کنید تا خواناتر شود!
