Τα τελευταία χρόνια μαθαίνω **σιγά σιγά ιαπωνικά**. Επισκέπτομαι την Ιαπωνία τακτικά και προσπαθώ να βυθιστώ στη γλώσσα, αλλά είναι δύσκολο, γιατί στις μέρες μας, με τη βοήθεια του Google Translate, είναι πολύ εύκολο να περάσεις χρόνο στην Ιαπωνία χωρίς να πεις ούτε λέξη ιαπωνικά. **Έτσι ο εγκέφαλός μου μπορεί να τεμπελιάσει**, αλλά τα καταφέρνω μια χαρά.

Ο προγραμματισμός έχει αρχίσει πρόσφατα να ακολουθεί την ίδια πορεία. Τα τελευταία 30 χρόνια, αν ήθελες να κάνεις οτιδήποτε με την τεχνολογία, **έπρεπε να μάθεις προγραμματισμό**. Ήταν ο μόνος τρόπος να επικοινωνήσεις με έναν υπολογιστή. Όμως τα τελευταία δύο χρόνια, με την άνοδο του προγραμματισμού με πράκτορες, αυτό έχει αλλάξει. Τώρα μπορείς να χρησιμοποιήσεις τη μητρική σου γλώσσα και να πεις σε έναν πράκτορα τεχνητής νοημοσύνης τι θέλεις να κάνει, και **αυτός θα γράψει το code για σένα** - μεταφράζοντας τις οδηγίες σου στον υπολογιστή.

Ακριβώς όπως δε χρειάζεται να περιμένω να μιλάω άπταιστα ιαπωνικά για να εξερευνήσω την Ιαπωνία, **δεν έχει πλέον κανένα νόημα να περνάς χρόνια για να γίνεις καλός στον προγραμματισμό** πριν αρχίσεις να φτιάχνεις πράγματα.

Αλλά αν θέλω πραγματικά να μπω στην ιαπωνική κουλτούρα και να κάνω Ιάπωνες φίλους, πρέπει να μάθω ιαπωνικά. Και, αν θέλεις να μπεις στον χώρο της τεχνολογίας, πρέπει ακόμα να μάθεις προγραμματισμό. Το code δεν είναι πλέον ο θυρωρός, αλλά είναι **η διαφορά ανάμεσα στο "να τα βγάζεις πέρα" και στο να ευδοκιμείς πραγματικά**.

Για να γίνεις καλός γρήγορα, χώρισε τον χρόνο μάθησής σου σε δύο κομμάτια:
1. **Μάθε προγραμματισμό.** Δούλεψε μέσα από το μάθημα Coding Fundamentals του Jiki και θα αποκτήσεις γερές βάσεις.
2. **Φτιάξε πράγματα.** Δούλεψε μέσα από το "Learn to Build", μπαίνοντας στα βαθιά, δημιουργώντας προϊόντα που μπορούν πραγματικά να χρησιμοποιήσουν οι άνθρωποι!

Αν θέλεις να μάθεις περισσότερα για τις σκέψεις μου σχετικά με το **πώς να μπεις στον χώρο της τεχνολογίας το 2026**, διάβασε [αυτό το άρθρο στο blog](https://jiki.io/blog/how-to-get-into-tech-in-2026).

Τις επόμενες μέρες, θα σου πω λίγα περισσότερα τόσο για τον προγραμματισμό όσο και για την κατασκευή, και πώς μπορείς να αξιοποιήσεις στο έπακρο το [Jiki](https://jiki.io). Μέχρι τότε, **ρίξου στη δουλειά και διασκέδασε!**
