Εξαιρετική δουλειά σε ένα γεμάτο επίπεδο. Συναρτήσεις που επιστρέφουν τιμές, χρώματα HSL και RGB, κίνηση, τυχαίοι αριθμοί, εμβέλεια, σενάρια και βρόχοι μέσα σε βρόχους. Αυτές είναι πολλές νέες ιδέες για να προσθέσεις στην εργαλειοθήκη σου με μια κίνηση.

Μην ανησυχείς αν κάποιες από αυτές σου φαίνονται ακόμα λίγο θολές. Θα επανέλθουν όλες σε διαφορετικά πλαίσια αργότερα στο μάθημα, και κάθε φορά θα γίνονται πιο οικείες.

Στη συνέχεια θα αρχίσουμε να παίρνουμε αποφάσεις στον κώδικα χρησιμοποιώντας εντολές `if`. Εδώ είναι που τα προγράμματά σου αρχίζουν πραγματικά να φαίνονται έξυπνα. Καλή διασκέδαση!
