Ta mission est de compléter le feu tricolore en dessinant les trois feux de couleur à l'aide des variables fournies.

On a déjà calculé les positions pour toi. Il ne te reste qu'à dessiner les cercles avec les bonnes variables et les bonnes couleurs.

Voici les variables qu'on a créées :

- `radius` : le rayon de chaque feu
- `centerX` : le centre horizontal des trois feux
- `topY` : le centre vertical du feu du haut (le rouge)
- `middleY` : le centre vertical du feu du milieu (l'orange)
- `bottomY` : le centre vertical du feu du bas (le vert)

Pour les couleurs, utilise `"red"`, `"amber"` et `"green"`.

Bonne chance !
