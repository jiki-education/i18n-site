به تازگی اعتبارسنجی شماره‌های ISBN کتاب‌ها را بررسی کردیم. یک فرمول رایج دیگر هم وجود دارد که برای بررسی شماره‌ها در زمینه‌های زیادی استفاده می‌شود و آن «الگوریتم لون» است. معروف‌ترین کاربرد آن پیدا کردن اشتباهات تایپی در شماره‌های کارت اعتباری است.

### «بررسی لون»

بررسی لون چند مرحله دارد:

- از **سمت راست‌ترین** رقم شروع کنید و به سمت چپ حرکت کنید، **مقدار هر رقم دوم را دو برابر** کنید.
- اگر دو برابر کردن رقمی عددی بزرگ‌تر از ۹ به‌دست دهد، ۹ را از آن کم کنید.
- سپس همه‌ی رقم‌ها را با هم جمع کنید.
- اگر مجموع بر ۱۰ بخش‌پذیر باشد، عدد معتبر است.

برای مثال، با `"067"` این مراحل را دنبال می‌کنیم:

```
0   6   7     // ارقام اصلی
0  12   7     // هر رقم دوم (از سمت راست) دو برابر شد
0   3   7     // ۱۲ بزرگ‌تر از ۹ است، پس ۹ از آن کم می‌شود → ۳
       10     // رقم‌ها را با هم جمع بزنید
     true     // ۱۰ بر ۱۰ بخش‌پذیر است، پس ۰۶۷ معتبر است
```

### کار شما

تابعی به نام `valid` (معتبر) بسازید که یک رشته بگیرد و اگر از بررسی لون عبور کرد `true` برگرداند و در غیر این صورت `false` برگرداند.

اعداد به‌صورت رشته داده می‌شوند و ممکن است برای خوانایی شامل فاصله باشند (برای مثال `"4539 1488 0343 6467"`). باید فاصله‌ها نادیده گرفته شوند.

چند نکته‌ی مهم:

- ورودی ممکن است شامل فاصله باشد — باید آن‌ها را نادیده بگیرید.
- اگر ورودی شامل هر کاراکتر دیگری باشد، باید `false` برگردانید.
- رشته‌هایی با طول ۱ یا کمتر (پس از حذف فاصله‌ها) **نامعتبر** هستند.
