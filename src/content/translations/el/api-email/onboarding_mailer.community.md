Είναι πολύ πιο πιθανό να πετύχεις μαθαίνοντας οτιδήποτε αν **είσαι μέλος μιας ομάδας**. Ο προγραμματισμός δε διαφέρει.

Αν θα ήθελες να λάβεις βοήθεια, να συζητήσεις για την πορεία σου στον προγραμματισμό ή απλώς να κάνεις παρέα με άλλους, υπάρχουν μερικά μέρη για να το κάνεις:
- [Το φόρουμ μας](https://jiki.io/r/forum): Το μέρος για πιο αργές, εκτενείς συζητήσεις. **Πήγαινε πιο βαθιά** εδώ.
- [Το Discord του Exercism](https://jiki.io/r/discord): Το μέρος για **ζωντανή συνομιλία** με άλλους που είναι συνδεδεμένοι. Ψάξε για τα κανάλια #jiki-chat και #jiki-get-help.
- [YouTube](https://jiki.io/r/youtube): Πάρε μέρος στις συνεδρίες ερωτήσεων και απαντήσεων (Ask Me Anything) και σε άλλες **ζωντανές μεταδόσεις** για να μου κάνεις τις ερωτήσεις σου!

Θυμήσου ότι σε αυτούς τους χώρους υπάρχουν άνθρωποι από πολλούς διαφορετικούς πολιτισμούς, οπότε **σε παρακαλώ να είσαι ευγενικός** με όλους όσο συνομιλείς.

Τα λέμε εκεί!
