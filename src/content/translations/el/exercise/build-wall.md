Την τελευταία φορά που είδες τον τοίχο, πρόσθεσες ένα επάνω στρώμα για να τον τελειώσεις. Σε αυτή την άσκηση, θα χτίσεις πάνω σε αυτό φτιάχνοντας έναν ολόκληρο τοίχο από την αρχή, 55 τούβλα συνολικά.

Ο τελικός τοίχος θα πρέπει να μοιάζει με αυτό:

<img src="/static/images/exercise-assets/build-wall/completed-wall.webp" alt="Ολοκληρωμένος τοίχος" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Πράγματα που πρέπει να ξέρεις:

- **Κάθε** τούβλο έχει ύψος 10 και πλάτος 20.
- Οι σειρές εναλλάσσονται ανάμεσα στο να ξεκινούν στην αριστερή άκρη (5 τούβλα), και στο να ξεκινούν εκτός οθόνης προς τα αριστερά (6 τούβλα). (Η κάτω σειρά είναι 5, η πάνω σειρά είναι 6.)
- Η συνάρτηση `rectangle` (ορθογώνιο) μπορεί να εμφανιστεί μόνο μία φορά στον κώδικά σου!

Ο σκοπός αυτής της άσκησης είναι να πειραματιστείς με τα μπλοκ `repeat` και τις συνθήκες μαζί. Υπάρχουν πολλοί διαφορετικοί τρόποι για να λύσεις αυτή την άσκηση. Η πρόκλησή σου είναι να τη λύσεις με έναν τρόπο που θα οδηγήσει σε καθαρό, ικανοποιητικό κώδικα.

Μια καλή ερώτηση να κάνεις στον εαυτό σου είναι: "Πώς θα το έκανε αυτό ένας χτίστης στον πραγματικό κόσμο;"
