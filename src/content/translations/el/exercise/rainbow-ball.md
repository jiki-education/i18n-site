Η δουλειά σου είναι να δημιουργήσεις μια μπάλα που αναπηδά τυχαία γύρω από τον καμβά, αφήνοντας ένα ουράνιο τόξο στο πέρασμά της.

Θα πρέπει να μοιάζει κάπως έτσι:

<img src="/static/images/exercise-assets/rainbow-ball/example.gif" alt="Κινούμενη μπάλα ουράνιου τόξου που αναπηδά γύρω από τον καμβά αφήνοντας ένα χρωματιστό ίχνος" style="width: 100%; max-width: 200px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Στα πλαίσια αυτής της άσκησης, έχεις στη διάθεσή σου τη συνάρτηση `Math.randomInt(min, max)` (τυχαίος ακέραιος), η οποία επιστρέφει έναν τυχαίο ακέραιο ανάμεσα στο `min` και στο `max` που της δίνεις.

Αφιέρωσε μερικά λεπτά για να σκεφτείς πώς θα μπορούσες να το λύσεις αυτό. Αυτό είναι το πιο πολύτιμο κομμάτι της άσκησης, γι' αυτό πάρε τον χρόνο σου και **γράψε τις ιδέες σου πριν διαβάσεις τον παρακάτω τύπο.**

Όταν έχεις μια ιδέα για την προσέγγισή σου, συνέχισε να διαβάζεις. Αλλά μη συνεχίσεις πριν αφιερώσεις λίγο χρόνο στη σκέψη!

## Ο Τύπος

Αυτό το έργο έχει να κάνει με το να έχεις μερικές μεταβλητές που είναι υπεύθυνες για τη θέση της μπάλας, οι οποίες αυξάνονται ή μειώνονται σταδιακά. Και άλλες μεταβλητές που ελέγχουν **πώς** κινείται η μπάλα και αλλάζουν όταν πληρούνται συγκεκριμένα κριτήρια.

### Σχεδίαση

- Ο πρώτος κύκλος που σχεδιάζεις πρέπει να βρίσκεται στη θέση `(5, 5)`.
- Όλοι οι κύκλοι πρέπει να έχουν ακτίνα `10`.
- Το χρώμα του κύκλου πρέπει να χρησιμοποιεί HSL, ξεκινώντας με απόχρωση `100` (πράσινο), κορεσμό `80` (έντονα χρώματα) και φωτεινότητα `50` (μεσαία φωτεινότητα).

### Κίνηση

- Αρχικά, σε κάθε επανάληψη πρέπει να μετακινείς την μπάλα `2` προς τα δεξιά και `1` προς τα κάτω.
- Η απόχρωση πρέπει να αυξάνεται κατά `1` κάθε φορά, μέχρι να φτάσει στο μέγιστο (`360`), και μετά να αρχίζει να μειώνεται ξανά. Ο κορεσμός και η φωτεινότητα δεν χρειάζεται να αλλάξουν.

### Αναπήδηση

- Μόλις η μπάλα φτάσει στην άκρη του καμβά, πρέπει να αλλάζει κατεύθυνση. (Έλεγξε τις συμβουλές αν δεν μπορείς να καταλάβεις πώς να το κάνεις.)
- Για να το κάνεις πιο διασκεδαστικό, πρέπει να αλλάζεις κατεύθυνση χρησιμοποιώντας τη συνάρτηση `Math.randomInt(min, max)`. Διάλεξε `min` (ελάχιστο) και `max` (μέγιστο) που δίνουν το στυλ κίνησης που θέλεις.

## Για να περάσεις τους ελέγχους

Σου δίνουμε μεγάλη ελευθερία σε αυτή την άσκηση. Ελέγχουμε ότι:

- Οι πρώτοι κύκλοι είναι σωστοί.
- Πάνω από το 80% του καμβά ζωγραφίζεται.

Οι αριθμοί που θα διαλέξεις για να το πετύχεις εξαρτώνται από εσένα. Πιθανότατα θα χρειαστείς ένα μπλοκ `repeat` που επαναλαμβάνεται από `500` έως `1000` φορές.

## Ανάλυσέ το...

Το κλειδί σε αυτή την άσκηση είναι να κάνεις τα πράγματα ένα-ένα:

1. Κάνε την μπάλα να αλλάζει χρώμα καθώς κινείται
2. Κάνε την να αναπηδά από τη δεξιά πλευρά
3. Κάνε την να αναπηδά από το κάτω μέρος
4. Κάνε την να αναπηδά τυχαία
