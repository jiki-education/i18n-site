Trabalho brilhante em um nível bem cheio. Funções que retornam valores, cores HSL e RGB, animação, números aleatórios, escopo, cenários e laços dentro de laços. É bastante ideia nova para acrescentar à caixa de ferramentas de uma vez só.

Não se preocupe se algumas ainda parecerem meio nebulosas. Todas voltam em outros contextos mais adiante no curso, e a cada vez ficam mais familiares.

A seguir, vamos começar a tomar decisões no código usando condicionais. É aí que os seus programas começam mesmo a parecer inteligentes. Divirta-se!
