Καλή δουλειά σε αυτό. Μπορείς πλέον να παρακολουθείς τιμές που αλλάζουν καθώς το πρόγραμμά σου εκτελείται, που είναι μια πραγματική πρόοδος από εκεί που ήσουν μερικά επίπεδα πριν.

Αυτή η ιδέα της κατάστασης θα συνεχίσει να εμφανίζεται σε όλο το μάθημα, και γίνεται πιο ενδιαφέρουσα κάθε φορά που τη συνδυάζουμε με κάτι νέο.

Ακολουθεί ένα γεμάτο επίπεδο. Θα δούμε συναρτήσεις που επιστρέφουν τιμές, και στη συνέχεια θα εξερευνήσουμε χρώματα, τυχαιότητα, κίνηση, εμβέλεια και βρόχους μέσα σε βρόχους. Καλή διασκέδαση!
