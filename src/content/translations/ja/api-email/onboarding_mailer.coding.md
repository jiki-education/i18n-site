プログラミングの学習は、技術的で難しいというイメージを持たれがちです。私がプログラミングを学び始めたのは8歳のときで、**突然かっこいいものを作れるようになった**ということ以外、何も知りませんでした。難しいものだなんて知らなかったのです。ただ、自分の創造性を出せる新しい場所ができた、と感じていました。

プログラミングを学ぶうえで、**それを極めるべき技術的な学問だとは思わないでください**。**自分**の創造性を解き放てる場所、**ものを作ったりパズルを解いたりするのを楽しめる**場所だと思ってほしいのです。プログラミングの本質は、問題を解くことだからです。

[どのプログラミング言語を学ぶか](https://jiki.io/blog/just-learn-to-code)は問題ではありません。大切なのは、**プログラミングがどう動くのか**をしっかり理解することです。

学習を進めるうちに、プログラミングが難しく、もどかしく感じられる時期も必ずあります。でもそれは、_プログラミング_が難しいからではなく、**学ぶこと自体が難しい**からです。何かを上達させたいなら、難しすぎると感じる時期を必ず通ります。それでも、踏ん張り続けるしかありません。

プログラミングの部分に努力する価値があるか不安なら、2026年になってもプログラミングを学ぶべき理由を説明した[こちらのブログ記事](https://jiki.io/blog/should-i-still-learn-to-code-in-2026)を読んでみてください。

読んでくれてありがとう！
