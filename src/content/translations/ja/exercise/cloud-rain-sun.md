この演習では、雲の後ろから太陽がのぞく雨の日の天気アイコンを描きます。完成すると、次のようになります。

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="完成した雲、雨、太陽のシーン" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

こちらでテンプレートを用意しました。図形は線の内側にぴったり収めてください。また、少し簡単にするために、雲のベース部分をコードにあらかじめ追加してあります。**この行は変更できません**（グレーアウトされ、ロックマークが表示されています）。

`circle`（円）と`ellipse`（楕円）の関数が必要です。楕円は雨粒にだけ使ってください。太陽や雲に使うと、うまく動きません。

必要な数値のほとんどは5で割り切れます（例：5、10、15など）。唯一の例外は、雨粒の横方向の半径で、これは`3`です。

楽しんでください！
