Μπορούμε να χρησιμοποιήσουμε κάτι που λέγεται template literals (πρότυπες συμβολοσειρές) για να εισάγουμε συμβολοσειρές μέσα σε άλλες συμβολοσειρές.

Έτσι, αντί να προσθέτουμε συμβολοσειρές, μπορούμε να έχουμε μια συμβολοσειρά ή πρότυπο που έχει κενές θέσεις για άλλες συμβολοσειρές μέσα του.

Για να το κάνουμε αυτό, χρησιμοποιούμε backticks (βαρείες) αντί για εισαγωγικά.

Τα backticks είναι διακριτικά σημεία σαν ανάποδοι τόνοι, όπως υποδηλώνει το όνομά τους αλλά πιθανόν να μην τα έχεις χρησιμοποιήσει ποτέ πριν, οπότε πρέπει να βρεις το σωστό πλήκτρο στο πληκτρολόγιό σου (συνήθως πάνω από το Tab, μαζί με την περισπωμένη).

Τα χρησιμοποιούμε για να δημιουργήσουμε ένα πρότυπο που μπορεί να περιέχει άλλες συμβολοσειρές. Έπειτα, για να εισάγουμε μια συμβολοσειρά στο πρότυπο, χρησιμοποιούμε μια άλλη παράξενη σύνταξη με δολάρια και άγκιστρα. Έτσι, για παράδειγμα, για να πετύχουμε το ίδιο `"hello " + name` που μόλις είδαμε με τη συνένωση, θα μπορούσαμε να γράψουμε:

```javascript
`hello ${name}` // "hello Jeremy" or "hello Jiki"
```

Και αυτό κάνει ακριβώς το ίδιο πράγμα με την πρόσθεση των συμβολοσειρών.

Αλλά όταν έχεις πολλές συμβολοσειρές που πρέπει να συνδυαστούν όλες σε ένα σημείο, αυτό μπορεί να είναι πολύ πιο αποδοτικό.

Θα σου πάρει λίγο χρόνο να συνηθίσεις αυτή ακριβώς τη σύνταξη, αλλά δεν υπάρχει τίποτα πραγματικά πολύπλοκο σε αυτήν.
