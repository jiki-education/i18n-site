Recebeste uma solução funcional para um labirinto, mas é muito longa e repetitiva. A tua tarefa é alterar o código para que fique com **o menor número de linhas possível**.

O segredo está em usar ciclos (_loops_ em inglês) `repeat` para tornar o código mais curto. Lembra-te de que um ciclo repeat tem esta sintaxe:

```javascript
repeat(3) {
  // O que quiseres repetir aqui.
}
```

A tua tarefa é tornar o código o mais curto possível: **22 linhas de código**. Isso implica pensar em quando vale a pena usar um ciclo repeat e quando não vale. Repara que as linhas em branco e as linhas só com comentários não contam para o objetivo, por isso podes espaçar o código à vontade para o tornar mais legível!

Boa sorte!
