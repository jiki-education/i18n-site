Η αποστολή σου σε αυτή την άσκηση είναι να δημιουργήσεις έναν καμβά γεμάτο πολύχρωμες πιτσιλιές ουράνιου τόξου!

Πρέπει να σχεδιάσεις **200 κύκλους** με τυχαίες ακτίνες, σε τυχαίες θέσεις, με τυχαία χρώματα. Το αποτέλεσμα θα πρέπει να μοιάζει κάπως έτσι:

<img src="/static/images/exercise-assets/rainbow-splodges/example.webp" alt="Πιτσιλιές ουράνιου τόξου" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Υπάρχουν μόνο τρεις κανόνες:

1. Διατήρησε τον κορεσμό και τη φωτεινότητα στην περιοχή 20 έως 80. Μπορείς είτε να χρησιμοποιήσεις σταθερές τιμές (ίσως 50 για κάθε μία, που μάλλον θα δείχνει καλύτερα) είτε να γίνεις πιο τολμηρός και να τις διαφοροποιήσεις και τις δύο.
2. Η ακτίνα των κύκλων πρέπει να είναι μεγαλύτερη από 1 και μικρότερη από 30 (αλλιώς οι κύκλοι θα είναι πολύύύύ μεγάλοι!). Μπορείς να επιλέξεις διαφορετικό εύρος, αλλά δεν μπορείς να βγεις εκτός αυτού.
3. Οι κύκλοι δεν επιτρέπεται να βγουν έξω από το κουτί. Ωστόσο, πολλοί κύκλοι θα πρέπει να αγγίζουν τις άκρες.

Γίνε δημιουργικός. Δοκίμασε μερικά διαφορετικά στυλ και δες τι σου φαίνεται ενδιαφέρον. Καλή διασκέδαση!
