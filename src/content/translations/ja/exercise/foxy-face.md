この演習では、`triangle`（三角形を描く関数）について学びます。7つの入力を使います。最初の6つの入力は、3つの角の座標のペアです。最後の入力は`color`（色）です。

- `x1`（1つ目の角のx座標）、`y1`（1つ目の角のy座標）
- `x2`（2つ目の角のx座標）、`y2`（2つ目の角のy座標）
- `x3`（3つ目の角のx座標）、`y3`（3つ目の角のy座標）
- `color`（色）：三角形の色（例：`"orange"`）

### キツネの顔を描く

ここでの課題は、三角形を使って幾何学的なキツネの顔を描くことです。

<img src="/static/images/exercise-assets/foxy-face/example.svg" alt="キツネの顔" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

この顔は左右対称です（左側と右側が同じ形です）。そして、全部で8つの三角形があります。

- 2つの白（`"white"`）の頬
- 2つの茶色（`"brown"`）の耳
- 2つのオレンジ（`"orange"`）の顔の半分
- 炭色（`"charcoal"`）の鼻（2つの三角形）

（これらの色を三角形に使ってください。また、それらを文字列（英: _string_）として書くことを確認してください！）

皆さんが始めやすいように、いくつかのパーツの輪郭を予め描いてあります。コメントに書かれた順番に従うと、少し楽になります。

さらに、使われている数字はすべて5の倍数です（例えば、`5`、`10`、`15`などは有効で、`1`、`2`、`3`、`4`、`6`、`7`、`8`、`9`、`11`などは無効です）。このパターンは、以降の演習でもよく出てきます。

最後に1つ。カーソルを当てると座標を見つけることができます。左側には便利ですが、右側は左右対称なので、カーソルを当てなくても右側の座標を求められますか？

がんばってください！
