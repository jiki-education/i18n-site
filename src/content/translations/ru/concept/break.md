Ключевое слово `break` можно использовать в любом месте тела любого цикла.

Телом цикла называется то, что находится между фигурными скобками. И когда Jiki видит `break`, он сразу выходит из цикла и переходит к тому коду, который стоит после него.

Так что если у нас есть условие прогнать цикл 50 раз, но остановиться, если пользователь выстрелил пять раз, мы можем поставить в начале цикл for, который считает до 50.

А в середине цикла можно поставить условие, которое проверяет, выстрелил ли пользователь уже пять раз, и если да, мы используем `break`, чтобы остановить цикл.

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // выходим из цикла
  }
}
```
