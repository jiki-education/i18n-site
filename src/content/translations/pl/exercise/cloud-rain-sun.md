W tym ćwiczeniu Twoim zadaniem jest narysowanie ikony pogody dla deszczowego dnia ze słońcem wyglądającym zza chmur. Po zakończeniu powinna wyglądać tak:

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="Ukończona scena z chmurą, deszczem i słońcem" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Narysowaliśmy dla Ciebie szablon. Twoje kształty powinny mieścić się tuż wewnątrz linii. Aby trochę ułatwić Ci zadanie, dodaliśmy do kodu podstawę chmury. **Nie możesz zmienić tej linii** (zobaczysz, że jest wyszarzona, a obok niej znajduje się symbol kłódki).

Będziesz potrzebować funkcji `circle` (okrąg) i `ellipse` (elipsa). Elips użyj tylko do kropel deszczu. Jeśli użyjesz ich do słońca lub chmur, kod nie zadziała.

Prawie wszystkie potrzebne liczby są podzielne przez 5 (np. 5, 10, 15 itd.). Jedynym wyjątkiem jest poziomy promień kropel deszczu, który wynosi `3`.

Miłej zabawy!
