Καλή δουλειά που ολοκλήρωσες το πρώτο επίπεδο του μαθήματος Βασικές Αρχές Προγραμματισμού του Jiki.

Μπορεί να μη νιώθεις ότι κάνεις ακόμα πολύ «πραγματικό» προγραμματισμό, αλλά μόλις απέκτησες μία από τις πιο σημαντικές δεξιότητες στον προγραμματισμό. Θα χρησιμοποιείς συναρτήσεις εκατοντάδες φορές την ημέρα από εδώ και πέρα, οπότε αυτό είναι πραγματικά η βάση για όλα τα υπόλοιπα.

Στη συνέχεια θα δούμε πώς να χρησιμοποιείς χρώματα για να σχεδιάζεις, και μετά θα αρχίσουμε να ανακατεύουμε και λίγη λογική στη διαδικασία. Καλή διασκέδαση!
