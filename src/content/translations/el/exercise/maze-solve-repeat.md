Σου έχει δοθεί μια λειτουργική λύση για έναν λαβύρινθο, αλλά είναι πολύ μεγάλη και επαναλαμβανόμενη. Η δουλειά σου είναι να αλλάξεις τον κώδικα ώστε να έχει **όσο το δυνατόν λιγότερες γραμμές**.

Το μυστικό για αυτό είναι να χρησιμοποιήσεις `repeat` βρόχους (_loops_ στα αγγλικά) για να κάνεις τον κώδικα πιο σύντομο. Για παράδειγμα, θυμήσου ότι ένας βρόχος `repeat` έχει αυτή τη σύνταξη:

```javascript
repeat(3) {
  // Ό,τι θέλεις να επαναλάβεις εδώ.
}
```

Η δουλειά σου εδώ είναι να κάνεις τον κώδικα όσο το δυνατόν πιο σύντομο: **22 γραμμές κώδικα**. Αυτό σημαίνει ότι πρέπει να σκεφτείς πότε είναι καλό να χρησιμοποιήσεις έναν βρόχο `repeat` και πότε όχι. Σημείωσε ότι οι κενές γραμμές και οι γραμμές που περιέχουν μόνο σχόλια δεν μετρούν στον στόχο, οπότε μη διστάσεις να αφήσεις κενά για να κάνεις τον κώδικα πιο ευανάγνωστο!

Καλή επιτυχία!
