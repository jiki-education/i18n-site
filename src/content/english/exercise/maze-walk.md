We're back with the maze, and we're going to take a step away from the automated solving for a moment. When you manually solved the maze before, if you had to move three steps forward, you had to write <define>`move()`</define> three times.

In this exercise, you're going to create a new function <define>`walk(numSteps)`</define> that takes a number of steps as its input, and moves forward that many times.

So using `walk(5)` should mean that you `move()` five times.

There's some sample code that solves the maze below your function. Once you've written your function, the code below will use it alongside <define>`turnLeft()`</define> and <define>`turnRight()`</define> to navigate through the maze.

Good luck!
