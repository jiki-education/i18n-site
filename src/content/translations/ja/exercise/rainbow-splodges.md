この演習での課題は、キャンバスいっぱいにカラフルな虹色のしぶきを描くことです。

半径、位置、色のすべてをランダムにして、200個の円を描いてください。結果は次のような感じになります。

<img src="/static/images/exercise-assets/rainbow-splodges/example.webp" alt="虹色のしぶき" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

ルールは以下の3つだけです。

1. 彩度と明度は20から80の範囲に収めてください。固定値（例えばどちらも50にすればきれいに見えるでしょう）にするか、もっと大胆に両方を変化させることもできます。
2. 円の半径は1より大きく30より小さい値にする必要があります（そうしないと、円がすっごく大きくなりすぎます！）。別の範囲を選んでも構いませんが、この範囲を超えてはいけません。
3. 円が枠の外にはみ出してはいけません。ただし、たくさんの円が枠の端に触れるようにしましょう。

創造力を発揮してください。いろいろなスタイルを試して、かっこいいと思うものを見つけてみましょう。楽しんでください！
