Την προηγούμενη φορά πρόσθεσες μια νέα συνάρτηση για να βοηθήσεις στην πλοήγηση στον λαβύρινθο: `turnAround()` (γύρνα). Έχουμε τον κώδικά σου στα αριστερά για να συνεχίσεις να δουλεύεις πάνω του.

Αυτή τη φορά αφαιρέσαμε τρεις από τις συναρτήσεις που χρησιμοποιούσες μέχρι τώρα. Η δουλειά σου σε αυτή την άσκηση είναι να τις υλοποιήσεις μόνος σου!

### Οι συναρτήσεις που πρέπει να γράψεις

Οι τρεις συναρτήσεις που πρέπει να δημιουργήσεις είναι οι `canTurnLeft()` (μπορώ να στρίψω αριστερά), `canTurnRight()` (μπορώ να στρίψω δεξιά) και `canMove()` (μπορώ να προχωρήσω).

Καμία από τις συναρτήσεις δεν έχει εισόδους. Όλες θα πρέπει να επιστρέφουν μια Boolean τιμή που να καθορίζει αν είναι δυνατόν να κινηθείς προς αυτή την κατεύθυνση.

Για να σε βοηθήσουμε, προσθέσαμε μια νέα συνάρτηση `look(direction)` (κοιτάζω). Αυτή η συνάρτηση δέχεται μία είσοδο - μια κατεύθυνση που μπορεί να είναι `"left"`, `"right"` ή `"ahead"`. Επιστρέφει μία από τις παρακάτω τιμές:

- `"start"` (Πού ξεκινάς)
- `"target"` (Πού προσπαθείς να φτάσεις)
- `"empty"` (Ο δρόμος είναι ελεύθερος!)
- `"fire"` (Προσοχή!)
- `"poop"` (Μπλιαχ!)
- `"wall"` (Ωχ!)

### Σημειώσεις για να σε βοηθήσουν

Εδώ είναι τρεις σημειώσεις που θα σε βοηθήσουν.

1. Μια καλή πρακτική σε μια τέτοια άσκηση είναι να **ξεκινήσεις δημιουργώντας τις συναρτήσεις** που χρειάζεται ο κώδικας για να τρέξει (δηλαδή τις `canTurnLeft()`, `canTurnRight()` και `canMove()`). Όρισε τις τιμές επιστροφής τους σε μια λογική προεπιλογή (είτε `true` είτε `false` σε αυτή την περίπτωση). Στη συνέχεια μπορείς να υλοποιήσεις τη λογική της κάθε συνάρτησης και να σημειώνεις πρόοδο κάθε φορά, αντί να παίρνεις συνέχεια ένα σφάλμα ότι η συνάρτηση δεν υπάρχει μέχρι να γράψεις ολόκληρο το πρόγραμμα.
2. **Δεν θα χρειαστεί να αλλάξεις κανέναν από τον υπάρχοντα κώδικά σου** για αυτή την άσκηση. Αντίθετα, πρόσθεσε τις τρεις συναρτήσεις στην κορυφή του κώδικα.
3. Μπορείς να γράψεις **περισσότερες συναρτήσεις** από αυτές που απαιτούνται, αν σε βοηθήσει.
