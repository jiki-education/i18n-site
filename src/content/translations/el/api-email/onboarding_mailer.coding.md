Η εκμάθηση προγραμματισμού έχει τη φήμη ότι είναι τεχνική και δύσκολη. Όταν ξεκίνησα να μαθαίνω προγραμματισμό, ήμουν ένα 8χρονο παιδί που δεν ήξερε τίποτα για τον προγραμματισμό εκτός από το ότι **ξαφνικά μπορούσα να φτιάχνω ωραία πράγματα**. Δεν ήξερα ότι υποτίθεται ότι ήταν δύσκολο. Απλώς ήξερα ότι ξαφνικά είχα μια νέα διέξοδο για τη δημιουργικότητά μου.

Καθώς μαθαίνεις προγραμματισμό, **δε θέλω να το βλέπεις ως κάποια τεχνική πειθαρχία που πρέπει να κατακτήσεις**, θέλω να το βλέπεις ως ένα μέρος όπου μπορείς να απελευθερώσεις τη **δική σου** δημιουργικότητα, όπου μπορείς να **διασκεδάσεις φτιάχνοντας πράγματα** και λύνοντας γρίφους. Γιατί αυτό είναι πραγματικά ο προγραμματισμός - επίλυση προβλημάτων.

Δεν έχει σημασία [ποια γλώσσα προγραμματισμού μαθαίνεις](https://jiki.io/blog/just-learn-to-code), αυτό που έχει σημασία είναι να αποκτήσεις πραγματικά καλή κατανόηση του **πως λειτουργεί ο προγραμματισμός**.

Καθώς προχωράς, θα υπάρξουν στιγμές που ο προγραμματισμός θα σου φαίνεται δύσκολος και απογοητευτικός. Αλλά αυτό δε συμβαίνει επειδή ο _προγραμματισμός_ είναι δύσκολος, αλλά επειδή **η μάθηση είναι δύσκολη**. Αν θέλεις να γίνεις καλός σε οτιδήποτε, πρέπει να περάσεις από φάσεις όπου η πρόκληση μοιάζει υπερβολική, αλλά πρέπει να επιμείνεις.

Αν δεν είσαι σίγουρος αν το κομμάτι του προγραμματισμού αξίζει τον κόπο, ρίξε μια ματιά σε [αυτό το άρθρο στο blog](https://jiki.io/blog/should-i-still-learn-to-code-in-2026) που εξηγεί γιατί πρέπει να μάθεις ακόμα προγραμματισμό το 2026.
