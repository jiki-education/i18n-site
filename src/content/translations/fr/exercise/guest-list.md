Tu es videur dans un club très sélect. Tu as la liste des invités (_guest list_ en anglais), mais tu as l'impression que beaucoup de gens dans la file d'attente (_queue_ en anglais) n'y figurent pas du tout, et tentent simplement leur chance pour entrer.

Avant que tu n'ouvres les portes, les organisateurs veulent savoir à quel point la situation est grave. Parmi les personnes actuellement dans la file d'attente, combien ne sont pas invitées du tout ?

Écris une fonction appelée `numChancersInQueue` (nombre de resquilleurs dans la file d'attente). La fonction a deux entrées :

- La première est la file d'attente, passée sous la forme d'un tableau de noms
- La seconde est la liste des invités, elle aussi un tableau de noms

Tu dois renvoyer le nombre de personnes dans la file d'attente qui ne figurent **pas** sur la liste des invités.

Amuse-toi bien !
