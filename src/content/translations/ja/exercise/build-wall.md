前回は壁に最後の一段を追加して、壁を完成させましたね。この演習では、それを踏まえて、壁全体をゼロから作ります。使うレンガは全部で55個です。

完成した壁は次のようになります。

<img src="/static/images/exercise-assets/build-wall/completed-wall.webp" alt="完成した壁" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

知っておきたいこと：

- **レンガはすべて**高さ10、幅20です。
- 段は、左端から始まる段（レンガ5個）と、画面の左外から始まる段（レンガ6個）が交互に並びます。（一番下の段が5個、一番上の段が6個です）
- `rectangle`（長方形）関数は、コードの中で一度しか使えません！

この演習の目的は、`repeat`ブロックと条件分岐を組み合わせて使ってみることです。この演習にはさまざまな解き方があります。綺麗で気持ちの良いコードになる方法で解いてみてください。

「現実の世界でレンガ積み職人だったら、どうやってこれを作るだろう？」と自分に問いかけてみてください。
