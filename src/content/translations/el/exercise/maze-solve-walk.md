Επιστρέψαμε ξανά στον λαβύρινθο! Την προηγούμενη φορά που ήσουν εδώ, χρησιμοποίησες τη συνάρτηση `move()` (κίνηση) για να μετακινηθείς ένα βήμα κάθε φορά. Αυτό λειτουργούσε, αλλά γίνεται αρκετά κουραστικό να γράφεις `move()` πολλές φορές στη σειρά!

Σε αυτή την άσκηση, αντικαταστήσαμε τη `move()` με μια νέα συνάρτηση (_function_ στα αγγλικά) που ονομάζεται `walk()` (περπάτημα). Αυτή η συνάρτηση παίρνει έναν αριθμό ως είσοδό της (_input_ στα αγγλικά) και προχωράει μπροστά τόσα βήματα. Για παράδειγμα, η `walk(3)` προχωράει μπροστά 3 βήματα και η `walk(1)` προχωράει μπροστά μόλις 1 βήμα.

Σε όλες τις μελλοντικές ασκήσεις, θα έχεις μια ενότητα «Συναρτήσεις» σαν την παρακάτω, που σου επιτρέπει να βλέπεις εύκολα ποιες συναρτήσεις έχεις στη διάθεσή σου και πώς λειτουργούν.

Χρησιμοποίησε την `walk()`, την `turnLeft()` (στροφή αριστερά) και την `turnRight()` (στροφή δεξιά) για να διασχίσεις τον λαβύρινθο και να φτάσεις στο πράσινο κελί-στόχο.
