Learning to code has a reputation for being technical and hard. When I started to learn to code, I was an 8-year-old kid who knew nothing about programming other than that **I could suddenly make cool stuff**. I didn't know it was supposed to be hard. I just knew I suddenly had a new outlet for my creativity.

As you learn to code, **I don't want you to see it as some technical discipline to master**, I want you to see it as somewhere you can unleash **your** creativity - where you can **have fun making things** and solving puzzles. Because that's what coding really is - problem solving.

It doesn't matter [what programming language you learn](https://jiki.io/blog/just-learn-to-code), what matters is that you build a really good understanding of **how coding works**.

As you progress, there will be times when coding does feel hard and frustrating. But this isn't because _coding_ is hard, it's because **learning is hard**. If you want to get good at anything, you have to go through phases where the challenge feels too much, but you have to persevere.

If you're not sure if the coding part is worth the effort, take a read of [this blog post](https://jiki.io/blog/should-i-still-learn-to-code-in-2026) that explains why you should still learn to code in 2026.
