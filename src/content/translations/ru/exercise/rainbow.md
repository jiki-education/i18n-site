Вам нужно создать красивый радужный узор из 100 вертикальных полос. Вот как он должен выглядеть:

<img src="/static/images/exercise-assets/rainbow/example.webp" alt="Радуга" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Радуга состоит из `100` полос, каждая из которых идёт сверху вниз и имеет ширину `1`. У первой полосы `x` (горизонтальная координата) должен быть равен `0`, а у последней полосы `x` должен быть равен `99`.

Чтобы задать цвет, используйте функцию `hsl(...)` (тон, насыщенность, светлота). Она возвращает (англ. _returns_) строку с цветом, которую затем можно использовать как последний вход функции `rectangle(...)` (прямоугольник). Значения насыщенности (англ. _saturation_) и светлоты (англ. _lightness_) лучше всего установить около `50`. У первой полосы **тон** (англ. _hue_) должен быть равен `0`. С каждой полосой тон должен увеличиваться и в итоге дойти примерно до 300.
