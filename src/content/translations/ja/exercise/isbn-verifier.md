すべての本にはISBN（International Standard Book Number）があります。これは、その本を一意に識別するための10桁の番号です。ISBNはそれぞれ一意であり、特定の形式に従っています。ある文字列がISBNであるかどうかをチェックする正式な検証プロセスも存在し、それをこの演習で作成します。

ISBNには通常ハイフンが含まれ、`3-598-21508-8`のようになります。

（13桁のISBNもありますが、この演習では無視してかまいません！）

### ISBNの検証

ISBNを検証するには、次のようにします：

- 左端から始め、各桁に10から1までカウントダウンする重みを掛けて合計します。
- その合計を11で割った余りを求めます。
- その余りが0であるかどうかをチェックします。

たとえば、ISBN `3-598-21508-8`の場合、次の条件が成り立つかどうかを調べます：

```
(3*10 + 5*9 + 9*8 + 8*7 + 2*6 + 1*5 + 5*4 + 0*3 + 8*2 + 8*1) % 11 === 0
```

結果が0であれば、そのISBNは有効です。

さらにいくつか重要な注意点があります：

- ISBNの末尾がXになることがあります。その場合、Xは`10`を表します。Xが他の位置にある場合、そのISBNは無効です。
- ISBNはハイフンあり・なしのどちらの形式でも書かれます。
- それ以外の文字が含まれると、ISBNは無効です。

### やるべきこと

`isValidIsbn(isbn)`（有効なISBNかどうかを判定する）という関数を作成してください。この関数はISBNの文字列を受け取り、有効な場合は`true`、無効な場合は`false`を返します。

### `Number(...)`関数

まだ取り上げていないことの1つに、`Number(str)`関数があります。この関数は文字列を受け取り、その文字列を数値として返します。つまり、`Number("1234")`と書くと`1234`が得られます。大文字で始まるため、少し変わった関数です。今は気にしないでください。なぜそうなっているかは、ずっと後で説明します。

詳しくは、<a href="/concepts/type-conversion" target="_blank" rel="noopener noreferrer">型変換の概念ページ</a>をご覧ください。
