Da última vez que viste o muro, acrescentaste uma camada no topo para o terminar. Neste exercício, vais mais longe: constróis um muro completo do zero, com 55 tijolos no total.

O muro final deve ter este aspeto:

<img src="/static/images/exercise-assets/build-wall/completed-wall.webp" alt="Muro concluído" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

O que precisas de saber:

- **Todos** os tijolos têm 10 de altura e 20 de largura.
- Os tijolos podem começar ou terminar **fora** do ecrã, se necessário, mas não podem estar **totalmente** fora do ecrã.
- As filas alternam entre começar na extremidade esquerda (5 tijolos) e começar fora do ecrã, à esquerda (6 tijolos). (A fila de baixo tem 5 e a fila de cima tem 6.)
- A função `rectangle` (retângulo) só pode aparecer uma vez no teu código!

O objetivo deste exercício é experimentares usar blocos `repeat` e condicionais em conjunto. Há muitas formas diferentes de resolver este exercício. O teu desafio é resolvê-lo de modo a obteres código limpo e satisfatório.

Uma boa pergunta para te fazeres é: «Como é que um pedreiro faria isto no mundo real?»
