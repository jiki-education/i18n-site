`break` कीवर्ड किसी भी लूप के अंदर कहीं भी इस्तेमाल किया जा सकता है।

कर्ली ब्रेसेस के बीच जो हिस्सा होता है, उसे लूप का अंदर का कोड कहते हैं। और जब Jiki इसे देखता है, तो वह तुरंत लूप से बाहर निकल जाता है और लूप के नीचे लिखे कोड पर चला जाता है।

मान लीजिए कि हमारी शर्त यह है कि लूप 50 बार चले, लेकिन हम चाहते हैं कि अगर उपयोगकर्ता पाँच बार शूट कर ले तो लूप रुक जाए। ऐसे में हम ऊपर एक `for` लूप लिख सकते हैं जो 50 तक गिनता है।

फिर लूप के बीच में एक शर्त लगा सकते हैं जो यह जाँचे कि उपयोगकर्ता ने पाँच बार शूट कर लिया है या नहीं। और अगर हाँ, तो लूप को रोकने के लिए हम `break` (लूप से बाहर निकलना) का उपयोग करते हैं।

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // लूप से बाहर निकलना
  }
}
```
