지난번에는 벽에 맨 윗줄을 쌓아 완성했어요. 이번 연습 문제에서는 완전히 처음부터 벽을 통째로 만들어요. 벽돌은 총 55개를 사용해요.

완성된 벽은 아래와 같아요:

<img src="/static/images/exercise-assets/build-wall/completed-wall.webp" alt="완성된 벽" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

꼭 알아둘 점이에요:

- 모든 벽돌은 높이 10, 너비 20이에요.
- 줄은 왼쪽 끝에서 시작하는 줄(벽돌 5개)과 화면 왼쪽 밖에서 시작하는 줄(벽돌 6개)이 번갈아 나타나요. (맨 아랫줄은 5개, 맨 윗줄은 6개예요.)
- `rectangle`(직사각형) 함수는 코드에서 단 한 번만 등장해야 해요!

이 연습 문제의 목표는 `repeat` 블록과 조건문을 함께 사용해 보는 거예요. 이 문제를 해결하는 방법은 아주 많아요. 여러분의 도전은 깔끔하고 만족스러운 코드로 풀어내는 거예요.

스스로에게 물어볼 만한 좋은 질문은 '실제 세상에서 벽돌공은 이걸 어떻게 할까?'예요.
