Στην πρώτη άσκηση σχεδίασης που ολοκλήρωσες, χρησιμοποίησες τη συνάρτηση `rectangle` (ορθογώνιο) για να γεμίσεις μερικά κενά σε έναν τοίχο. Σε αυτή την άσκηση, χτίζουμε πάνω σε αυτό χρησιμοποιώντας έναν βρόχο για να προσθέσουμε την επάνω στρώση σε έναν τοίχο.

Όλες οι στρώσεις εκτός από την επάνω είναι ήδη ολοκληρωμένες. Πρέπει να προσθέσεις την τελευταία στρώση των 5 τούβλων. Ο τελικός τοίχος θα πρέπει να μοιάζει έτσι:

<img src="/static/images/exercise-assets/finish-wall/completed-wall.webp" alt="Ολοκληρωμένος Τοίχος" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Πράγματα που πρέπει να γνωρίζεις:

- Κάθε τούβλο έχει ύψος 10 και πλάτος 20.
- Η συνάρτηση `rectangle` μπορεί να εμφανίζεται μόνο μία φορά στον κώδικά σου!
- Το σωστό χρώμα είναι `"brick"`.

Ξαναχρησιμοποίησε τις ιδέες που χρησιμοποιείς πρόσφατα και θα τα καταφέρεις. Καλή επιτυχία!
